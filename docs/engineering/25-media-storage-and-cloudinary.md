# 25. Media Storage and Cloudinary

> Version: V1.0
>
> Status: Technical Documentation
>
> Last Updated: August 2026

---

# 1. Purpose

The Media Storage system is responsible for storing, processing, optimizing, and delivering all user-uploaded media throughout CartFlow.

Instead of storing files on the application server, CartFlow stores media securely in Cloudinary while keeping only metadata and URLs inside PostgreSQL.

---

# 2. Objectives

The media system should:

- Store uploaded media securely.
- Deliver media quickly.
- Reduce storage costs.
- Optimize images automatically.
- Support future video uploads.
- Scale with platform growth.

---

# 3. Storage Architecture

```
User

↓

FastAPI

↓

Cloudinary Upload API

↓

Cloudinary Storage

↓

Optimized URL

↓

PostgreSQL

↓

Frontend
```

The backend never permanently stores uploaded files.

# 31. Summary

The CartFlow Media Storage system leverages Cloudinary to provide secure, scalable, and optimized media management.

By separating media storage from application storage, automatically optimizing images, and delivering content through a global CDN, the platform ensures fast performance, lower infrastructure costs, and a smooth user experience.
