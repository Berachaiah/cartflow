# 33. Recommendation

The design system should be treated as a reusable component library rather than a collection of individual screens.

Every new page should be built by composing existing components wherever possible. Introducing new colors, spacing values, typography styles, or interaction patterns should require updating this document first to preserve consistency across the platform.

When a new UI component is created, it should be documented with its purpose, variants, states, accessibility considerations, and implementation guidelines so it can be reused throughout CartFlow instead of duplicated.
