{# The launch splash, shared by every page because every page extends base. WHY IT IS A PARTIAL WITH ITS OWN CSS. The previous version was a Tailwind soup (`bg-background`, `animate-pulse`, `bg-primary`) inside base.html: the light theme silently fell back to a flat cream rectangle because `--c-card` and `--c-bg` are nearly the same value there, so the card the mark sat on disappeared and the whole screen looked washed out next to the dark one. Here each theme gets a deliberate treatment instead of two themes sharing one set of tokens. The mark is the app's own logo, not a decorative substitute: on first load this screen is the only thing a user sees, and a generic spinner would be the first impression of a product that has a real mark. #}
