# Every entry used to be a `>=` range, and that is how this environment drifted:
# the project was written against FastAPI 0.111, and the first Windows install

# alone changes the asyncio fixture defaults, and Starlette 1.10 deprecates

# These are the versions the full suite passes on (381 passed, 0 failed) and that
# the messaging page was verified against in a browser at 375px and 1280px.
# They are not guesses about what "should" work.
#
# To move a pin: change it here, install into a fresh venv, run the whole suite,
# and commit the bump on its own. A pin nobody has run the tests against is a
# different kind of drift, not a fix for it.
#
# Transitive dependencies (starlette, anyio, h11, ...) are deliberately NOT
# listed: they follow from these pins, and hand-pinning the whole closure turns
# every security bump into a manual audit of 40 packages the project doesn't use.
